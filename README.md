# AssetStorePilot

A skillset for Copilot that helps discover, compare, and purchase-reference assets from the Unity Asset Store.

## Included skill

- `unity-asset-store-pilot` at `.github/skills/unity-asset-store-pilot/SKILL.md`

This skill guides Copilot to:

- gather user requirements,
- identify Unity Asset Store candidates with source links,
- provide concise comparisons and recommendations,
- require explicit user confirmation before any purchase-oriented action.
